# Chrome Web Store

Yes, this Manifest V3 extension can be submitted for Google's review. It has not been submitted or approved. Google requires a one-time developer registration fee; strict zero-payment distribution remains the unpacked installation method unless you already own a registered developer account.

Before submission:

- Add official 16/32/48/128px extension icons, listing screenshots and store description.
- Add a publisher contact address to the deployed privacy policy, review it, and link it in the dashboard.
- Declare screenshot/page content collection, transmission to the owner's backend and AI providers, and the single purpose of question assistance.
- Explain why `activeTab`, `scripting`, `storage`, and the optional study-service host permission are needed.
- Reviewers need no link; confirm the shared allowance has capacity during review.
- Test the packaged extension on actual target question sites. Image-only highlight coordinates can be imprecise.
- Make no guaranteed accuracy, unlimited usage, or 5,000-answers/hour claims.

Registration: https://developer.chrome.com/docs/webstore/register
